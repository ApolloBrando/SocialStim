# Current gameplay scope

Owner direction, 2026-10-20: the game has only day and night gameplay periods.

- Day: group discussion, responses, voting, vote reveal, last words and elimination.
- Night: role target selection, action resolution and authorized results.
- Morning reports transition back into the next day's discussion.
- Relationships develop through ordinary discussion interactions.
- Free Time is cancelled: no social/exploration/visit phase, optional toggle,
  extra action budget, dedicated dialogue pool or background relationship events.

This overrides older mission text, plans and PR descriptions that proposed the
cancelled activity. The two implementation stacks still require integration;
this scope applies to both. Existing enum values for retained features must not
be renumbered when removing cancelled entries.
